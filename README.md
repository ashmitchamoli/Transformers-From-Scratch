# Transformers-From-Scratch
To train a model, fill in the hyperparamters in the `train.py` file and run it. Model will automatically be saved at the end of training.

Model weights can be loaded using the `.loadModelWeights()` function in the `Transformer` class. Make sure to put the `transformer_ckpt` directory in the same directory as the script, or alternatively provide a search path in the `.loadModelWeights()` method.
